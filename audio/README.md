# Эталонный голос

Положите сюда короткую запись голоса, который хотите клонировать:

- длительность **5–15 секунд**;
- формат: `wav`, `mp3`, `ogg`, `m4a`, `flac` — VoxCLode сам конвертирует в WAV;
- желательно **16 kHz, mono**, без музыки и сильного шума;
- говорите обычным темпом, без сильной эмоциональной окраски.

Пример:

```text
audio/voice.wav
```

Затем укажите этот путь в поле «Эталонный голос» или нажмите `Ctrl+V`, если файл скопирован в Проводнике.

> Аудиофайлы не коммитятся в репозиторий: голос может быть персональными данными.
> Для режима «Дизайн голоса» эталон не нужен.
